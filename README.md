## Rencana Fitur

Tiga fitur yang direncanakan dalam proyek ini adalah:

1. Tampilan halaman utama aplikasi.
2. Navigasi antarhalaman dalam aplikasi.
3. Pengelolaan dan penampilan data sederhana.

## Cara Menjalankan

Proyek ini merupakan aplikasi Android yang dibuat menggunakan Android Studio.

Untuk menjalankan aplikasi:

1. Buka folder proyek menggunakan Android Studio.
2. Tunggu proses Gradle Sync selesai.
3. Hubungkan perangkat Android atau jalankan Android Emulator.
4. Klik tombol **Run** di Android Studio untuk menjalankan aplikasi.

Jika proses setup Android Studio atau emulator belum selesai, konfigurasi tersebut perlu diselesaikan terlebih dahulu sebelum aplikasi dapat dijalankan.
