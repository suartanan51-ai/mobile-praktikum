## Tahap 1 — Membaca REST Endpoint dan JSON

**Endpoint:** https://jsonplaceholder.typicode.com/posts/1

- **HTTP Method:** GET
- **Status Code:** 200 OK (jika request berhasil)
- **Resource:** posts
- **Format response:** JSON

**Field JSON yang ditemukan:**
1. `userId` — ID pengguna yang membuat post.
2. `id` — ID post.
3. `title` — Judul post.
4. `body` — Isi post.

**Catatan:** Endpoint digunakan untuk mengambil satu data post berdasarkan ID. JSONPlaceholder merupakan API latihan dengan data contoh. Operasi penambahan, pengubahan, dan penghapusan disimulasikan sehingga tidak tersimpan secara permanen.
